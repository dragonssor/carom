# 당구 (3구 · 4구, 안드로이드)

한 기기에서 둘이 번갈아 치는 캐롬 당구입니다. 예전 iOS 앱 BB 당구의 조작 방식을 참고했고, 이름과 그림은 새로 만들었습니다. Kotlin, 외부 라이브러리 없이 Canvas로 그립니다.

## 실행
Android Studio에서 이 폴더를 열고 ▶ Run. (AGP 8.7.3, Kotlin 2.1.0, minSdk 24, 가로 화면 고정)

APK만 받으려면: https://github.com/dragonssor/carom/releases/download/latest/billiards.apk (main에 올라갈 때마다 GitHub Actions가 새로 빌드)

## 조작
화면(테이블)은 돌아가지 않습니다. 실제 당구장에서 테이블 주위를 걸어 다니듯 폰을 돌려 가며 칩니다.
1. 첫 번째 손가락으로 공을 보낼 곳을 누르기: 그쪽으로 조준
2. 그대로 뒤로 당기기: 큐가 손가락을 따라 당겨지고, 당긴 거리가 힘
3. 누른 채로 두 번째 손가락을 대고 움직이기: 큰 수구가 나타나고 당점 이동 (좌우 회전, 밀어치기, 끌어치기)
4. 두 번째 손가락을 떼고, 첫 번째 손가락을 떼면 샷. 당기기 전 위치로 돌아와서 떼면 취소
- 아래쪽 작은 수구 버튼: 한 손가락으로 당점을 고르는 화면
- 되돌리기: 직전 샷 이전으로 / 리플레이: 직전 샷을 공 이동 경로와 함께 다시 보기

## 규칙
- 플레이어 1은 흰 공, 플레이어 2는 노란 공. 레일 위아래의 점수 알이 각자의 점수
- 3구: 두 목적구를 모두 맞히고, 두 번째 공에 닿기 전에 쿠션 3번 이상이면 1점
- 4구: 빨간 공 두 개를 맞히면 1점. 상대 공을 맞히면 파울로 1점 감점, 차례 넘김
- 득점하면 계속 치고, 실패하면 차례가 넘어감. 목표 점수는 메뉴에서 선택

## 구조
- `engine/Physics.kt`: 공의 3차원 회전, 미끄러짐에서 구름으로의 마찰, 쿠션 반발과 회전, 공 충돌, 조준 예측
- `engine/Rules.kt`: 3구, 4구 판정
- `engine/Game.kt`: 턴, 점수, 되돌리기, 리플레이 기록
- `ui/BilliardsView.kt`: 그리기와 터치 조작
- `app/src/test`: 엔진 단위 테스트 (`./gradlew test`)
